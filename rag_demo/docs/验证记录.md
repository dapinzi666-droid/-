## 接下来怎样完成最终验收

1. 在可正常访问模型下载站的实际演示电脑上按新手说明安装。
2. 执行 `--prepare` 下载并记录官方模型版本及校验值。
3. 执行 `--smoke`，再运行完整 `--experiments`。
4. 对照 `data/knowledge.txt`人工核查模型答案，填实验记录，保存Notebook真实输出和报告。
5. 在同一台电脑上预演并录制备用视频。

以下仅为开发云端记录，本机用户无需操作这些云环境设置。若继续在当前云端运行，已保存网络配置草稿，新增 `huggingface.co` 与 `cas-bridge.xethub.hf.co`。需在环境设置中审阅、保存并发布；保存草稿本身不会改变当前实例网络，也不能证明下载已可用。
