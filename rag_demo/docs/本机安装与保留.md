# 在你自己的电脑安装、运行，并保留本地版本

这份说明对应原来的选题A基础RAG项目。不是后面截图里的LoRA微调作业。

## 先说清楚：谁在操作哪台电脑

网页版助手能准备项目文件、安装脚本和下载链接，当前没有控制你电脑的工具。你需要在自己的电脑下载、解压并双击入口；脚本才会真正把软件、依赖和模型下载到本机。不能把云端检查当作你的电脑已安装成功。

本入口先按 **Windows 10/11 x64** 编写；不支持32位Windows或ARM64。建议16GB内存，8GB可尝试；至少8GB可用空间，创建完整备份建议预留12GB以上。macOS/Linux继续使用原说明，不要运行这些Windows入口。

## 你现在只需要做什么

1. 下载本机安装版ZIP，解压出整个 `rag_demo` 文件夹，放到固定位置，例如 `D:\rag_demo`。没有D盘时选择你能写入的文件夹。
2. 双击 **`install_local_windows.bat`**。第一次保持联网，不要关闭运行窗口。
3. 如果电脑已有匹配的64位Python3.11/3.12，脚本会复用它；没有时会下载官方安装器并打开窗口，由你点击 **Install Now**。安装完成后关闭安装窗口，脚本继续。
4. 等待依赖下载、离线依赖重建检查、模型下载和真实问答自检。只有全部成功，才打开Notebook。
5. 以后双击 **`run_local_windows.bat`** 即可再次打开项目。正常情况下不重新下载模型或依赖。
6. 要保存一份可恢复的本地副本，关闭Notebook后双击 **`backup_local_windows.bat`**。它会在项目文件夹的上一层生成ZIP，可再复制到U盘或移动硬盘。

脚本不需要你填写API密钥，也不训练模型。首次联网下载通常明显慢于以后启动，时间取决于网络和电脑。模型下载失败时会停止并保留已下载内容，不会用固定答案替代。

## 使用哪些版本

| 软件或组件 | 版本/来源 | 由谁下载 |
|---|---|---|
| Python（电脑原来没有时） | 官方Windows x64 Python 3.12.10安装器 | 安装入口从python.org下载，并验证Windows数字签名及PSF发布者 |
| 已有Python3.11 | 可复用；另保留3.11.9官方安装器供对应小版本重建 | 本机脚本 |
| PyTorch | CPU版2.6.0+cpu，无需显卡 | 官方PyTorch软件源 |
| Transformers | 4.48.3 | PyPI官方源 |
| Chroma | 1.0.20 | PyPI官方源 |
| JupyterLab | 4.3.5 | PyPI官方源 |
| 中文Embedding模型 | BAAI/bge-small-zh-v1.5 | 官方Hugging Face模型仓库 |
| 中文生成模型 | Qwen/Qwen2.5-0.5B-Instruct | 官方Hugging Face模型仓库 |

这两个Python安装器版本是为了匹配项目和可获取的Windows完整安装包，**不表示当前最新安全版本**。若已有兼容环境，优先复用，不要求卸载或替换系统Python。

如需手动下载Python3.12安装器，官方地址：

<https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe>

如果官方安装窗口显示Modify/Repair而不是首次安装，请先关闭并反馈当前情况，避免误操作已有安装。

## 本地会保留哪些文件

| 位置 | 保存内容 |
|---|---|
| `software/` | 已验证签名的官方Python安装器、来源及SHA256记录 |
| `.venv/` | 这台电脑当前使用的Python依赖环境 |
| `wheelhouse/` | 匹配这台Windows和Python小版本的依赖wheel、全部精确版本和SHA256锁 |
| `models/` | 两个真实模型、版本及文件SHA256 |
| `results/` | 你实际运行生成的问答和对照报告 |
| `local_installation.json` | 本机安装阶段与实际自检状态；失败时不会保留旧的成功标记 |
| `local_python_minor.txt` | 离线恢复时选择匹配的Python小版本 |

保留整个项目文件夹即可保留当前本地版本。第一次安装后不要随意移动文件夹或只复制Notebook，因为虚拟环境会记录路径。

## 怎样制作、恢复完整备份

### 制作

先完成本机安装与真实自检，再双击 `backup_local_windows.bat`。备份前会重新检查当前安装器、wheel与模型，而不是仅相信以前的成功记录。

ZIP包含代码、资料、模型、依赖安装文件、官方Python安装器和实际结果，并带逐文件SHA256清单。它**不直接复制 `.venv`**，因为虚拟环境通常不能直接迁移；恢复时用保留的安装材料重建。

### 恢复

1. 把完整备份ZIP解压到一个新的、固定的文件夹。
2. 双击 **`restore_local_windows.bat`**。
3. 它使用备份中的安装器、匹配Python小版本的wheel及本地模型重建，不从软件源或模型站重新下载。
4. 依赖离线重建和真实问答自检成功后才进入Notebook。

恢复目标仍应是相同的Windows x64/Python小版本，不保证跨平台。Windows本身仍需具备可用的证书信任链和微软运行库；如果离线无法验证安装器签名，应先补齐受信任系统环境，不要跳过校验。

轻量项目下载ZIP只包含代码和安装入口，**不是已经装有模型和依赖的离线备份**。只有你在本机成功准备后生成的完整备份，才包含那些大文件。

## 失败时怎么办

- 保留窗口，截图最后报错并说明正在执行哪一步。已下载内容不会因为失败自动删除。
- Python官网、PyPI、PyTorch软件源或Hugging Face连接失败，需要先解决对应站点的访问问题；不能把反复重试当作成功。
- 如果出现`DLL load failed`、`WinError 126`等，应检查微软Visual C++ x64运行库。官方安装入口：<https://aka.ms/vs/17/release/vc_redist.x64.exe>。不要把这条故障说明当作已经诊断了你的电脑。
- 如果看到“还未准备模型”，先完成安装入口；如果回答达到长度上限，按Notebook说明调整上限并重新比较。

## 怎样算项目真的完成

安装入口会进行一次真实问答自检，**它还不能替代整份课堂实验**。进入Notebook后，还要运行完整切分/温度实验，核对答案、保存真实结果，并录制备用演示视频。

当前开发环境的Python官网和模型站访问仍返回403；Windows脚本没有在你的电脑上实测，不能宣称已经替你安装完成。代码、缓存校验与备份逻辑的检查结果见验证记录。
